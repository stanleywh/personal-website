# Design reference screenshots

The original screenshot attachments were not available to copy into the
repository. Place the four reference images in this directory using these names:

- `home-original-100.png`
- `home-target-80.png`
- `tracker-original-100.png`
- `tracker-target-80.png`

The `target-80` images show the desired physical appearance. The implemented
site should be compared with them while the browser itself is at 100% zoom and
the viewport matches the reference capture.
